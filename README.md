# 仁美國小社區小小探險家

公開網站：https://sunanna37.github.io/renmei-community-explorer/

六站真實照片尋寶、景點知識闖關、背包準備、集章與證書。使用純 HTML、CSS 和 JavaScript，透過 GitHub Pages 發布。

每次重新開啟連結都是新探險，分頁進度獨立；同一分頁重新整理會保留進度。網站無學生帳號與後端資料庫。
